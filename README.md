## 🎮 游戏操作
- **左箭头**：向左移动
- **右箭头**：向右移动
- **空格键/上箭头**：跳跃 / 空翻
- **X键**：丢弃NPC

## 🎯 游戏目标
在雪山上滑雪，躲避雪崩，收集NPC伙伴，完成各种空翻动作来获得高分！

## 🏔️ 游戏机制
- **雪崩追击**：雪崩会持续追击玩家，不要被追上！
- **NPC伙伴**：拾取企鹅和雪怪可以获得移动能力加成！
- **空翻得分**：完成360度空翻可以获得额外分数
- **地形挑战**：利用地形起伏进行跳跃和空翻
- **石头障碍**：小心避开石头，撞击会摔倒或失去NPC！

## 🐧 NPC系统
- **企鹅**：提供速度加成和空翻能力增强
- **雪怪形态1**：提供大幅速度加成，但无法空翻
- **雪怪形态2**：平衡的能力加成，并可携带企鹅
- **组合效果**：雪怪形态2 + 企鹅 = 最强组合！

## ⚡ 特殊技巧
- **空翻加速**：完成空翻后获得短时间速度提升
- **伤害抵抗**：在加速状态下可以抵抗石头伤害(空翻失败仍会摔倒！)
- **企鹅护盾**：二阶段携带的企鹅可以抵抗一次摔倒
- **得分倍率**：连续高难度动作可以提升得分倍率

## ⚠️ 注意事项
- 摔倒会重置所有得分倍率
- 失去NPC后NPC拾取有冷却时间
- 合理利用地形是获得高分的关键
